# Basic Weather App

## About the Project

This project is a Basic Weather App developed using Python.

It allows the user to enter a city name and displays the current weather information using real-time weather data.

## Features

- Allows the user to enter a city name.
- Displays the temperature.
- Displays humidity.
- Displays wind speed.
- Displays weather information.
- Uses real-time weather data.
- Handles invalid city names.
- Handles internet connection errors.

## Technologies Used

Python

urllib module

json module

Open-Meteo Weather API

## How to Run

1. Make sure Python is installed.

2. Open the project folder in Command Prompt.

3. Run the following command:

python weather_app.py

4. Enter the city name.

5. The current weather information will be displayed.
