  *BMI Calculator*

*About the Project

>This project is a simple BMI Calculator developed using Python as part of the Oasis Infobyte Python Programming Internship.

>The program accepts the user's weight and height, calculates the Body Mass Index (BMI), and displays the corresponding BMI category.

*Features

>Accepts weight in kilograms (kg).

>Accepts height in meters (m).

>Calculates BMI using the standard formula.

>Displays the calculated BMI to two decimal places.

>Displays the corresponding BMI category.

>Validates invalid and non-positive inputs.

>Handles non-numeric input.

>Allows the user to calculate BMI again without restarting the program.

>Provides clear and simple output.


*BMI Formula*

BMI = Weight (kg) / Height² (m²)

*BMI Categories*

BMI Range	Category

Below 18.5	Underweight
18.5 – 24.9	Normal weight
25.0 – 29.9	Overweight
30.0 and above	Obesity


> Note: BMI is a general screening measure and should not be treated as a complete assessment of an individual's health.

*How to Run*

1. Make sure Python 3 is installed.


2. Open the project folder in Command Prompt.


3. Run the following command:



python bmi_calculator.py

4. Enter your weight in kilograms.


5. Enter your height in meters.


6. The program will display the calculated BMI and category.


7. Choose whether you want to perform another calculation.
